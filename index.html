The document object model (DOM), consists of elements or nodes. The elements have attribute and text nodes, or another child element node.

Step 1: Access the element by selecting an individual element by id, a group of elements by class, or traversing the DOM tree with siblings, parents, or childs.

For example, use:

var itemOne = document.getElementById('one');

var elements = document.getElementsByClassName('hot');
if(elements.length > 0) {
    for(var i = 0; i < elements.length; i++) {
        elements[i].className = 'cool';
    }
}

You can select by CSS as well:

var el = document.querySelector('li.hot');
el.className = 'cool';

var els = document.querySelectorAll('li.hot');
els[1].className = 'cool';

Traverse the DOM using:

var firstItem = startItem.firstChild;
var lastItem = startItem.lastChild;
var prevItem = startItem.previousSibling;
var nextItem = startItem.nextSibling;

Set attributes of an element using: firstItem.setAttribute('class', 'complete');

Step 2: Work with the nodes. Access and update its text node or attribute values, work with the HTML content, create new nodes, etc.

Elements has other elements as child nodes, attributes, and text nodes.

To access a text node, use nodeValue:

var itemTwo = document.getElementbyId('two');
var elText = itemTwo.firstChild.nodeValue;
elText = elText.replace('pine nutes', 'kale');
itemTwo.firstChild.nodeValue = elText;

Step 2: Create new elements by creating an element, appending an optional text node to it, then appending it to another element.

var newEl = document.createElement('li');
var newText = document.createTextNode('quinoa');
newEl.appendChild(newText);
var position = document.getElementsByTagName('ul')[0];
position.appendChild(newEl);

To remove an element:

var removeEl = document.getElementsByTagName('li')[3];
var containerEl = removeEl.parentNode;
containerEl.removeChild(removeEl);

Events

There are many events, such as UI events, keyboard, mouse, focus, form, and mutation events.
Event listeners listen for events and are added to elements. Once the event on the element occurs, the corresponding function triggers.
It is best to assign event listeners to parent nodes for performance and maintainability.

function charCount(e, param) {
    e.preventDefault();
    var lastkey = document.getElementById('lastkey');
    lastkey.textContent = 'Last key in ASCII code: ' + e.keyCode + param;
}
el = document.getElementById('message');
el.addEventListener('keypress', function(e) {
    charCount(e, 54);
}, false);
